# Simple Wallpaper Changer for Windows

Simply changes the wallpaper based on user input from the Pictures Directory in the users home directory.

## Description

Simply changes the wallpaper based on user input from the Pictures Directory in the users home directory.

## Getting Started
### Dependencies

No outside dependencies.

### Installing Executing program

```Powershell
git clone https://github.com/Wesley-Blake/winWallpaper
cd "Your path here"
python wallpaper_changer.py
```

## Help

Make sure that the photos in your Pictures directory are .jpg or .png
